Cursor 仓库问答

在 GitHub 仓库页面右下角点开浮窗提问，Cursor Cloud Agent 会在云端克隆仓库、阅读代码后回答。

Cursor API key

在 Cursor Dashboard → API Keys 创建 User API Key（以 crsr_ 开头），粘贴到这里。key 只保存在本机浏览器，不会同步。

模型

留空就用你在 Cursor 里设置的默认模型。只是读代码回答问题，选便宜一点的模型更省额度。

回答语言

问答记录

每个仓库的对话保存在本机，同一仓库的追问会复用同一个云端 agent（不用重新克隆）。在浮窗里点“＋”可以开新对话。

说明

  • 只支持公开仓库：agent 用匿名 git clone 拉代码，私有仓库会克隆失败。
  • 每次提问都会在 Cursor 云端运行 agent，按 Cloud Agent 计费，消耗你的 Cursor 额度。
  • 第一次提问要启动云端环境并克隆仓库，通常要等几十秒；同一仓库的追问会快一些。
  • User API Key 对你的 Cursor 账号有管理员级权限：不要把装好 key 的扩展分享给别人。
